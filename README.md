# 个人简历 & 作品集网站模板（软件工程师版）

一个零依赖、零图片、加载极快的个人主页模板：深色开发风 + 终端签名卡片 + 时间轴经历。

## 文件结构

```
resume-site/
├── index.html   # 全部内容（样式、结构、交互都在这一个文件里）
└── README.md    # 本说明
```

## 替换清单（搜索对应文字即可定位）

| 位置 | 要替换的内容 |
| --- | --- |
| 网页标题 `<title>` | 你的真实名字与职位 |
| Hero 区 | `你的名字`、`Software Engineer / 全栈开发`、状态文案、城市、经验、GitHub |
| 终端卡片 about.ts | 名字、技术栈、城市、邮箱 |
| 关于我 | 自我介绍段落 + 右侧信息列表 |
| 技术栈 | 前端 / 后端 / 工具三组技能标签 |
| 精选作品 | 6 张示例卡片 → 替换成你的真实项目（封面、标题、说明、标签、演示/代码链接） |
| 经历 | 时间轴 3 条示例 → 换成你的工作/教育经历 |
| 联系我 | 邮箱、下载简历按钮（替换成真实 PDF）、GitHub/掘金/知乎链接 |

所有示例按钮（查看演示 / 查看代码 / 下载简历）点击会弹出「示例链接」提示，替换真实链接后即可正常工作。

## 上线部署（Cloudflare Pages，永久免费 ✅ 已上线）

**当前线上地址（永久有效）：** https://my-resume-site-ba6.pages.dev

1. 打开 https://dash.cloudflare.com 登录（免费注册，只需邮箱）；
2. 左侧「Workers 和 Pages」→「创建」→「继续前往 Pages（旧版工作流）」→「拖放文件」；
3. 填写项目名称（会生成永久域名 `项目名.pages.dev`）→ 上传本文件夹或打包的 zip →「部署站点」；
4. 约 1 分钟后部署成功，即可通过 `项目名.pages.dev` 永久访问，全程免费、无需域名、无需备案。

> 更新方法：每次改完 `index.html`，进入该项目 →「创建部署」→「直接上传」重新上传新版即可，地址不变。

## 备选：EdgeOne Makers（腾讯云，免费）

1. 打开 https://console.cloud.tencent.com/edgeone/makers ，登录后开通 Makers（免费）；
2. 「项目」→「直接上传」→ 填写项目名称 → 上传本文件夹或打包的 zip；
3. 点击「开始部署」，约 10~30 秒后部署成功，会生成一个预览链接。

> ⚠️ 注意（实测）：EdgeOne 免费默认域名只提供 **3 小时限时预览链接**；想长期稳定访问需购买自定义域名（约 60 元/年），若使用「含中国大陆」加速区还需 ICP 备案。适合作为临时预览或与 Cloudflare 双线并存。
